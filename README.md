# 记账本 - Web版记账应用

一个简洁、快速的移动优先记账应用，使用 React + TypeScript + IndexedDB 构建。

## 功能特性

### MVP 功能

✅ **记账功能**
- 支持收入/支出记录
- 金额以分为单位存储，避免浮点误差
- 支持二级分类（如 餐饮/早餐）
- 多账户管理（现金、借记卡、信用卡）
- 日期时间选择
- 备注和标签

✅ **列表浏览**
- 按日期分组显示
- 搜索功能（备注/标签）
- 按月份筛选
- 新增记录高亮提示

✅ **统计分析**
- 月度收支统计（总收入/总支出/结余）
- 分类饼图统计
- 预算管理（总预算/已用/剩余/超支提示）

✅ **重复账单**
- 支持每日/每周/每月重复
- 自动生成交易记录
- 暂停/恢复/删除规则

✅ **设置**
- 数据导出/导入（JSON格式）
- 深色模式（跟随系统/手动切换）

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **数据存储**: IndexedDB (通过 Dexie.js)
- **图表**: Recharts
- **日期处理**: date-fns

### 技术栈选择理由

1. **React + TypeScript**: 类型安全，生态成熟，适合复杂状态管理
2. **Vite**: 快速的开发服务器和热更新
3. **Tailwind CSS**: 移动优先，易于定制iOS风格界面
4. **IndexedDB**: 本地存储，支持离线使用，容量大
5. **Dexie.js**: 简化IndexedDB操作，提供Repository封装便于未来替换后端

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:5173` 启动

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 数据模型

### 核心实体

- **Transaction**: 交易记录（金额以分为单位存储）
- **Category**: 分类（支持父子关系的二级分类）
- **Account**: 账户（现金/借记卡/信用卡）
- **RecurringRule**: 重复账单规则
- **Budget**: 预算

### 数据持久化

所有数据存储在浏览器的 IndexedDB 中，刷新不会丢失。通过 Repository 层封装，便于未来替换为云端存储。

## 产品架构

### 页面结构

1. **账单页** (`/transactions`): 查看、添加、编辑、删除交易记录
2. **统计页** (`/stats`): 月度统计、分类分析、预算管理
3. **重复页** (`/recurring`): 管理重复账单规则
4. **设置页** (`/settings`): 外观设置、数据导入导出

### 底部导航

采用iOS风格的底部标签栏导航，方便单手操作。

## 特性说明

### 重复账单

- **生成策略**: 按月视图自动展开到具体日期
- **避免重复**: 检查是否已存在对应日期的交易记录
- **灵活控制**: 可暂停、恢复或删除规则

### 预算管理

- 设置月度总预算
- 实时显示已用金额和剩余预算
- 超支时红色警告提示
- 进度条可视化展示

### 数据导入导出

- 导出为 JSON 格式
- 包含所有账户、分类、交易、重复规则、预算数据
- 导入时会覆盖现有数据（请谨慎操作）
